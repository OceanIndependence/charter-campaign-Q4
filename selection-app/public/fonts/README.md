# Gotham fonts (licensed — not committed)

Drop the licensed TTFs into this folder with these exact filenames; the
`@font-face` rules in `src/app/globals.css` already point at them. Until the
files are present the page falls back to Helvetica Neue.

- `Gotham-Light.ttf` — Gotham, weight 300 (body)
- `Gotham-Book.ttf` — Gotham, weight 400 (stat numbers)
- `Gotham-Medium.ttf` — Gotham, weight 500 (labels / all-caps runs)
- `GothamCond-Medium.ttf` — Gotham Condensed, weight 500 (display)
- `GothamCond-Bold.ttf` — Gotham Condensed, weight 700 (cover headline)
